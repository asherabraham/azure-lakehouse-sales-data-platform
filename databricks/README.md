# Azure Databricks

This directory contains Databricks-related assets used for data transformation
and lakehouse processing.

## Responsibilities
- Transforming data from Bronze to Silver layers
- Building Gold layer fact and dimension tables
- Implementing Delta Lake–based upserts and SCD logic

## Technologies Used
- Apache Spark (PySpark)
- Delta Lake
- Unity Catalog (for governance and schema management)

## Structure
- `notebooks/` contains transformation notebooks
- Job or workflow definitions may be added as the project evolves
